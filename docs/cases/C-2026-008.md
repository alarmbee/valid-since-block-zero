# Rövid leírás

- **Cél:** az SZTFH-től információ kérése arról, hogy mikor lesz elérhető részletes útmutató a „validáló szolgáltató” tevékenységének pontos tartalmáról, illetve lesz-e átmeneti iránymutatás arra, hogyan kerülhető el a Büntető Törvénykönyv szerinti felelősség addig, amíg több validáló szolgáltató nem áll rendelkezésre.
- **Címzett:** Szabályozott Tevékenységek Felügyeleti Hatósága (SZTFH) elnöke.
- **Feladó:** országgyűlési képviselő (országgyűlési képviselőcsoport nevében).
- **Dátum:** 2026. január 13. (Budapest).
