# Kérdések

Az alábbiakban találhatók a validációs előírással kapcsolatban felmerülő, rövid és közérthető kérdések.  
Ezeket a kérdéseket GitHubon, pull request formájában bővítheted.

A kérdések alapján **jogilag precíz, forrásalapú** megkereső levelek (email sablonok) is készülnek, amelyek a tisztázatlan pontokra **tételes választ** kérnek. Ezeket a [Email minták](/templates/) oldalon találsz.
